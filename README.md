# hnm

Install a complete **agent documentation harness** into any project:

- `docs/prd/`, `docs/adr/`, `docs/spec.md`
- `AGENTS.md` + `CLAUDE.md` symlink
- `$feature-dev` skill (one-question loop before implementation)
- `$git-commit` skill (conventional commits from the diff)

## Install

```bash
go install github.com/AkaraChen/hnm/cmd/hnm@latest
```

## Usage

```bash
hnm init
hnm init --force
hnm agents show
hnm agents write --body "# Project instructions"
hnm prd create --id cli-run --body "..."
hnm adr create --id error-types --status Accepted --body "..."
hnm adr list
hnm skills list
hnm skills path feature-dev
```

## What gets written

AGENTS.md and docs/spec.md with initial workflow content, CLAUDE.md (symlink), docs/prd/, docs/adr/. The `feature-dev` and `git-commit` skills are bundled inside the binary. Init installs their complete directories under `.agents/skills/` and links each into `.claude/skills/` for agent discovery. `hnm skills get|path` also remains available. Existing skill files are preserved; `--force` refreshes bundled files without deleting unrelated skills.

`hnm init` also installs a Python documentation-review hook into `.codex/hooks/spec_doc_review.py` and merges its configuration into `.claude/settings.json` and `.codex/hooks.json`. Existing settings and hooks are preserved; repeated init does not duplicate entries. `--force` resets harness files and the script, while preserving unrelated hook/settings entries. Invalid settings are reported without overwriting them.

The hook pauses the first direct `git commit` attempt per session and HEAD to request a spec/PRD/ADR review; retry is allowed. It is a workflow reminder, not a security gate. Python 3 and Git must be available. For [Codex](https://developers.openai.com/codex/hooks), trust the project and review the installed hook in `/hooks`; hnm does not bypass runtime trust or override disabled hooks. Restart [Claude Code](https://code.claude.com/docs/en/hooks) to load settings changes. Existing AGENTS.md files remain unchanged on normal init; use the entity write command or deliberately reset with force to adopt the seeded instructions.

## Develop

The CLI composes an importable package generated by [ctxl](https://github.com/AkaraChen/ctxl) from `context.schema.json`. `internal/generated` is generated-owned and replaced in full; `cmd/hnm` adds hnm-owned hook installation.

    just generate
    go build ./cmd/hnm
