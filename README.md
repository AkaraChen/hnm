# hnm

Install a complete **agent documentation harness** into any project:

- `docs/prd/`, `docs/adr/`, `docs/spec.md`
- `AGENTS.md` + `CLAUDE.md` symlink
- `$feature-dev` skill (one-question loop before implementation)
- `$git-commit` skill (conventional commits from the diff)

## Install

```bash
go install github.com/AkaraChen/hnm/cmd/hnm@latest
```

## Usage

```bash
hnm init
hnm init --force
hnm prd create --id cli-run --body "..."
hnm adr create --id error-types --status Accepted --body "..."
hnm adr list
hnm skills list
hnm skills path feature-dev
```

## What gets written

AGENTS.md, CLAUDE.md (symlink), docs/spec.md, docs/prd/, docs/adr/. The `feature-dev` and `git-commit` skills are bundled inside the binary and served via `hnm skills get|path`.

## Develop

The CLI is generated by [ctxl](https://github.com/AkaraChen/ctxl) from `context.schema.json`; `cmd/hnm` is generated-owned and replaced in full.

    just generate
    go build ./cmd/hnm
